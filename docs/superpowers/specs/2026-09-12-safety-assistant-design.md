## 1. 목표와 원칙

### 목표
안전관리자의 반복 업무 중 **결정론적으로 정의 가능한 부분을 전부 프로그램이 처리**하고,
판단·문장화가 필요한 부분만 AI가 초안을 만들며, **최종 확인과 서명은 사람이 한다.**

### 4대 원칙

1. **법적 책임은 위임 불가.** 안전관리자의 직무(산안법 제17조, 시행령 제18조)는 법이 사람에게 부여한 것이다. AI는 초안 작성자이지 이행 주체가 아니다.
2. **결정론 우선.** 날짜 계산, 주기 산정, 금액 집계, 서식 출력은 코드가 한다. AI에게 시키면 틀린다.
3. **근거 없는 문장 금지.** 생성 문서의 모든 의무 항목에는 법조문 출처를 병기하고, 근거가 없으면 "근거 확인 불가"로 표기한다.
4. **로컬 우선.** 현장 자료는 로컬 폴더에 두고, 외부 전송은 사용자가 명시적으로 지시할 때만 한다.

### 위임 수준 정의

| 수준 | 의미 | 적용 예 |
|---|---|---|
| **L0 – 불가** | 사람만 가능. AI 사용 금지 | 점검 실시, 서명·날인, 시정지시, 발주처 제출 결정 |
| **L1 – 초안** | AI가 초안 → 사람이 전량 검토·수정 | 위험성평가 항목 도출, 교육 교안, 시정 요구서 문안 |
| **L2 – 검증 후 자동** | 프로그램이 생성 → 사람이 승인 클릭 | 법정 의무 캘린더, 점검표 서식, 사용내역서 |
| **L3 – 완전 자동** | 사람 개입 없음 | 기한 알림, 서류 누락 탐지, 파일 정리·백업 |

## 3. 시스템 구조

```
KIAI/
├─ apps/
│  ├─ legal-cost/            # 기존 - 법정경비 출력 엔진 (재사용)
│  └─ safety-assistant/      # 신규
│     ├─ src/safetyassist/
│     │   ├─ site.py         # 현장 설정(공사금액·구조규모·공종·업체)
│     │   ├─ duty.py         # ★ 법정 의무 규칙엔진 (핵심)
│     │   ├─ calendar.py     # 의무 → 날짜 전개
│     │   ├─ registry.py     # 지적사항·교육·점검 대장 (SQLite)
│     │   ├─ docs/           # PDF·PPTX 생성기 (Pretendard)
│     │   └─ audit.py        # 누락·기한초과 탐지
│     ├─ rules/              # ★ 법정 의무를 YAML로 외부화 (법 개정 시 여기만 수정) [작성됨]
│     ├─ site.example.yaml   # 현장 설정 예시 [작성됨]
│     └─ tests/
├─ skills/
│  ├─ safety-risk-assessment/   # 위험성평가 초안 (L1)
│  ├─ safety-education/         # 교육 교안 (L1)
│  ├─ safety-corrective/        # 시정 요구서 (L1)
│  └─ safety-daily/             # 일일 브리핑 (L2)
└─ site-data/                   # 로컬 현장 데이터 (.gitignore)
```

### 3계층 분리

| 계층 | 담당 | 구현 | 이유 |
|---|---|---|---|
| **규칙 계층** | 법정 의무 정의 | `rules/*.yaml` | 법 개정 시 코드 수정 없이 YAML만 교체 |
| **엔진 계층** | 날짜·집계·서식 출력 | Python (결정론적, 테스트 100%) | 계산 오류 = 법 위반. AI에게 맡길 수 없음 |
| **AI 계층** | 판단·문장화 | Claude Code 스킬 | 초안만 생성, 항상 사람 검토 |

### 규칙 YAML 예시

```yaml
- id: patrol-round
  name: 작업장 순회점검
  basis:
    law: 산업안전보건법 제64조제1항제4호
    rule: 산업안전보건법 시행규칙 제80조
  applies_when: { industry: 건설업 }
  frequency: { every_days: 2, text: "2일에 1회 이상" }
  output: { form: 순회점검표, format: pdf }
  delegation: L2

- id: tbm
  name: 작업 전 안전점검회의(TBM)
  basis:
    law: 근거 확인 불가
    note: 법령상 직접 규정 없음. 관리감독자 직무(시행령 제15조)와 연계 운영
  frequency: { every_days: 1 }
  delegation: L1
```

### 0-3. 데이터 위치 (2026-09-14 확인)

현장 자료 폴더: `C:\Users\XANNY\OneDrive\문서\00. 안양 인덕원 현장 안전_보건 파트 관리사항`

**OneDrive 동기화 폴더라는 점이 설계에 영향을 준다.**

| 대상 | 위치 | 이유 |
|---|---|---|
| 문서 산출물(PDF·PPTX) | 위 OneDrive 폴더 | 자동 백업·다른 기기 접근. 원하는 동작 그대로다 |
| 대장 데이터베이스(SQLite) | `%LOCALAPPDATA%\SafetyAssistant` (동기화 제외) | OneDrive가 동기화 중인 SQLite 파일을 잠그거나 충돌 사본을 만들면 **대장이 손상된다.** 증빙 데이터가 깨지는 사고이므로 동기화 폴더 밖에 둔다 |
| 데이터베이스 백업 | OneDrive 폴더 하위 `_backup` | 프로그램이 일 1회 파일을 복사한다. 복사본은 잠기지 않아 안전하다 |

폴더 내부 구조는 기존 자료를 건드리지 않는다. 프로그램은 지정한 하위 폴더에만 쓰고,
기존 파일은 사용자가 명시적으로 지정할 때만 읽는다.
