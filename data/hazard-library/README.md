# SMP 위험요인 표준 사전 (Hazard Library)

건설현장 공종별 유해·위험요인과 감소대책을 구조화한 데이터셋이다.
SMP의 **일상활동 모듈(TBM·순회점검)** 과 **위험성평가 모듈**이 공통으로 참조한다.

## 목적

1. TBM 작성 시 해당 공종의 위험요인을 골라 쓰게 해 입력 시간을 줄인다
2. 위험성평가 실시 시 누락 없이 위험요인을 검토하게 한다
3. 각 위험요인에 **산업안전보건기준에 관한 규칙 조문을 매핑**해, 위험성평가와
   법령 의무 점검이 동시에 이뤄지게 한다

## 파일 구성

```
data/hazard-library/
  README.md               이 문서
  schema.json             JSON Schema (데이터 형식 정의)
  taxonomy.json           공종 분류, 재해유형 분류, 대책 유형
  hazards/
    common.json           현장 공통
    temp-works.json       가설공사
    earthwork.json        토공·굴착·흙막이
    ...공종별
  validate.mjs            형식·조문 검증 스크립트
```

## 파일 ↔ 공종 매핑

한 파일이 여러 공종의 작업을 함께 담는 경우가 있다. 검증 스크립트가 "데이터가 없는
공종"으로 표시하는 코드는 아래 파일이 실질적으로 포함하고 있다.

| 파일 | 대표 공종코드 | 함께 포함하는 공종 |
|---|---|---|
| `common.json` | COMMON | 전 공종 공통 |
| `temp-works.json` | TEMP | 가설통로, 고소작업대 |
| `earthwork.json` | EXCV | 성토·다짐, 토사운반 |
| `earth-retaining.json` | EARTH | 어스앵커, 계측관리 |
| `pile-foundation.json` | PILE | 항타·천공·현장타설말뚝 |
| `formwork-concrete.json` | FORM | **REBAR**(철근), **CONC**(콘크리트 타설) |
| `steel-welding.json` | STEEL | **WELD**(용접·화기), 데크플레이트 |
| `lifting.json` | LIFT | 타워크레인, 리프트, 줄걸이 |
| `machinery.json` | MACH | 지게차, 항타기, 장비 정비 |
| `electrical.json` | ELEC | 가설전기, 정전·활선작업 |
| `finishing.json` | MASON | **WATERP**(방수), **PAINT**(도장), **WINDOW**(창호), **ROOF**(지붕), **INTER**(내장) |
| `confined-demolition.json` | CONFIN | **DEMO**(해체·철거), 석면 해체 |
| `plumbing-hvac.json` | PLUMB | 덕트, 기계실, 시운전 |
| `road-pavement.json` | ROAD | 아스팔트 포장, 야간 도로작업 |
| `pipeline.json` | PIPE | 트렌치 굴착, 하수관 내부작업 |

| `landscape.json` | LAND | 식재, 전정, 예초 |

세부 공종이 늘어나면 별도 파일로 분리한다.

## 법적 근거

| 용도 | 근거 |
|---|---|
| 위험성평가 실시 의무 | 산업안전보건법 제36조 |
| 위험성평가 절차·방법 | 「사업장 위험성평가에 관한 지침」(고용노동부고시) |
| 위험요인별 안전조치 | 산업안전보건기준에 관한 규칙 (각 항목에 조문 매핑) |
| 평가 결과의 근로자 공유 | 산업안전보건법 제36조제3항 |
| 기록 보존 | 산업안전보건법 제164조제1항 |

## 데이터 출처 및 한계

**출처**: 산업안전보건기준에 관한 규칙 조문, 한국산업안전보건공단(KOSHA)의 공종별
위험성평가 자료 및 안전보건 기술지침(KOSHA GUIDE)에서 확인되는 일반적 위험요인을
정리한 것이다.

**한계 — 반드시 읽을 것**

- 이 사전은 **참고용 체크리스트이지 법정 위험성평가 결과가 아니다.**
  산업안전보건법 제36조의 위험성평가는 **해당 사업장의 실제 작업을 대상으로**
  실시해야 하며, 이 목록을 그대로 옮겨 적는 것은 평가를 실시한 것이 아니다.
- 현장 고유의 위험요인(지형, 인접 시설, 기상, 동시 작업 등)은 이 사전에 없다.
  반드시 현장 확인을 통해 추가해야 한다.
- 조문은 작성 시점 기준이다. 법령은 개정되므로 **시행 중인 조문을 확인**해야 한다.
- 위험성 추정값(`severityDefault`, `likelihoodDefault`)은 **일반적 상황을 가정한
  출발점**일 뿐이며, 실제 값은 현장 조건에 따라 달라진다. 그대로 쓰면 안 된다.
- 조문이 확인되지 않은 항목은 `legalBasis`에 `"근거 확인 불가"`로 표기한다.

이 한계는 SMP 화면과 출력물에도 표시한다.

## 검증

```bash
node data/hazard-library/validate.mjs
```

id 중복, 분류 코드 정합성, 근거 누락, 보호구만으로 구성된 대책(제거·대체·공학적
통제를 검토하지 않은 경우)을 검사한다. 오류가 있으면 종료코드 1로 끝난다.
