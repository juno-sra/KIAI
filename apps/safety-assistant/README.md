# 안전관리 AI 비서

건설현장 안전관리자의 법정 의무를 계산하고 문서를 만드는 프로그램.

설계문서: `docs/superpowers/specs/2026-09-12-safety-assistant-design.md`

## 원칙

날짜·주기·집계는 코드가 계산한다. 계산 오류가 곧 법 위반이 되므로
AI에게 맡기지 않는다. AI는 판단과 문장화(위험성평가 항목, 교육 교안,
시정 요구서 문안)만 초안으로 만들고, 확인과 서명은 사람이 한다.

## 사용

```bash
pip install -e '.[dev]'
cp site.example.yaml site.yaml     # 현장 값 입력 (커밋되지 않음)

# 이 현장에 적용되는 의무 목록
python -m safetyassist.cli --site site.yaml duties

# 기간 내 이행 기한
python -m safetyassist.cli --site site.yaml calendar --from 2026-09-01 --to 2026-09-30
```

## 구성

| 모듈 | 역할 |
|---|---|
| `rules/*.yaml` | 법정 의무 정의. 법 개정 시 여기만 고친다 |
| `models.py` | 규칙·현장·이행시점 자료구조 |
| `rules.py` | 규칙 로더. 스키마 위반 시 조용히 넘기지 않고 오류를 낸다 |
| `site.py` | 현장 설정 로더 |
| `applies.py` | 의무가 이 현장에 적용되는지 판정 |
| `schedule.py` | 의무를 날짜로 전개 |
| `cli.py` | 명령줄 출력 |

## 지금 단계에서 하지 않는 것

- **법령 원문 대조.** 전 규칙이 `verified: false`이며 출력에 `[미검증]`으로 표시된다.
  교육시간·보존기간 등 확인하지 못한 수치는 비워 두었다. 추정값을 채우면
  틀린 값이 검증된 값처럼 보인다.
- **휴무일 처리.** 주말·공휴일을 구분하지 않으므로 일일 주기 의무(TBM, 순회점검)가
  비작업일에도 전개된다. 실제 작업일 달력을 입력받도록 개선해야 한다.
- **사유 발생형 의무의 날짜 전개.** 채용 시 교육, 재해조사표처럼 사유가 있어야
  하는 의무는 날짜를 미리 찍지 않고 목록으로만 보여준다.
- **대장·문서 출력.** Phase 2 이후다.
