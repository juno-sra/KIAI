# 법정 의무 규칙 (rules/)

안전관리 AI 비서의 **규칙 계층**. 법정 의무를 코드가 아닌 YAML로 정의해,
법령 개정 시 프로그램 수정 없이 이 디렉터리만 교체한다.

## 스키마

```yaml
- id: patrol-round              # 규칙 식별자 (영문, 고유)
  name: 작업장 순회점검          # 사람이 읽는 이름
  category: 점검                 # 점검 | 위험성평가 | 교육 | 서류 | 보고 | 보존
  basis:                        # 법적 근거
    law: 산업안전보건법 제64조제1항제4호
    rule: 산업안전보건법 시행규칙 제80조
    notice: null                # 고시가 근거인 경우
    note: null                  # 보충 설명
  verified: false               # 법령 원문 대조 완료 여부
  applies_when:                 # 적용 조건 (site.yaml과 대조)
    role: 도급인
  frequency:                    # 주기
    every_days: 2
    text: "2일에 1회 이상"
  deadline: null                # 기한형 의무인 경우 (예: 사유 발생일로부터 1개월)
  output:                       # 산출물
    form: 순회점검표
    format: pdf
  delegation: L2                # L0 위임불가 | L1 초안 | L2 검증후자동 | L3 완전자동
  penalty: null                 # 위반 시 제재 (확인된 경우만)
```

## verified 필드

`verified: false`는 **법령 원문 대조가 아직 안 된 항목**을 뜻한다.
초판은 전부 `false`다. 원문(국가법령정보센터 PDF 등)과 1:1 대조한 항목만
`true`로 바꾼다. 프로그램은 `false` 항목을 산출물에 "미검증" 표시한다.

`basis.law`가 `근거 확인 불가`인 항목은 법령상 직접 근거가 없다는 뜻이며,
이는 미검증과 다르다. 해당 의무는 법정 의무가 아니라 관행 또는 계약상 의무다.

## 현장 적용 조건

`applies_when`은 `site.yaml`의 현장 설정과 대조해 평가한다.
본 현장 확정 조건:

- 공사금액 120억원 이상 → 안전관리자 1명 선임, 산업안전보건위원회 설치 대상
- 도급인 지위, 안전보건총괄책임자 선임됨 → 제62조·제64조 의무 적용
- 유해위험방지계획서 **비대상** → 관련 규칙 없음
- 근로자 개인정보 미취급 → 교육 규칙의 산출물은 인원수·직종 단위
