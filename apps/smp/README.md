# SMP (Safety Management Program)

건설현장 안전관리자의 법정 업무 기록을 모듈 단위로 조합해 쓰는 Windows 설치형
데스크톱 프로그램.

설계문서: `docs/superpowers/specs/2026-09-16-smp-*.md`

## 현재 상태

공통 기반 1단계 — 핵심 로직 구현 완료. Electron 셸과 화면은 다음 단계다.

| 패키지 | 내용 | 상태 |
|---|---|---|
| `@smp/core` | ULID, 이벤트, 램포트 시계, 공통 마스터, 문서 설정 | 구현·시험 완료 |
| `@smp/crypto` | AES-256-GCM 암호화, 키 보관·내보내기·복구 | 구현·시험 완료 |
| `@smp/sync` | 폴더 구조, 이벤트 로그, 병합, 무결성, 권한 점검 | 구현·시험 완료 |
| `@smp/module-sdk` | 모듈 인터페이스, 등록기, 형식 검사 | 구현·시험 완료 |
| `desktop` | Electron 셸 | 미착수 |

## 개발

```bash
npm install
npm run build      # TypeScript 빌드
npm test           # 시험 실행
npm run typecheck
```

Node 22 이상이 필요하다. 런타임 의존성은 없고 Node 내장 모듈만 쓴다.
현장 PC에 설치되어 수 년간 도는 프로그램이므로 의존성을 최소로 유지한다.

## 설계상 알아둘 점

**클라우드에 DB 파일을 두지 않는다.** OneDrive는 파일 잠금을 지원하지 않아
여러 기기가 단일 DB 파일에 쓰면 손상된다. 대신 기기별로 자기 `.jsonl`에만
덧붙이고, 조회용 SQLite 캐시는 로컬(`%LOCALAPPDATA%`)에 둔다. 캐시가 깨져도
이벤트를 다시 읽어 복구된다.

**잘린 줄을 버리지 않는다.** 동기화 중인 파일은 마지막 줄이 잘려 보일 수 있다.
개행으로 끝나지 않는 줄은 읽지 않고 남겨 두었다가, 완성되면 그때 읽는다.

**격리의 실제 차단선은 앱이 아니라 OneDrive 폴더 공유 권한이다.** 앱은 선언된
역할과 실제 접근 권한이 어긋났는지 탐지해 알릴 수만 있다.

**개인정보는 ID로만 참조한다.** 기록 본문(`.jsonl`)에 성명을 쓰지 않는다.
성명은 암호화된 명부에만 있으므로, 파일이 유출되어도 누구의 기록인지 특정되지
않는다.

**없는 법적 근거를 지어내지 않는다.** 보존기간 규칙은 근거 조문을 반드시 적고,
확인되지 않으면 `'근거 확인 불가'` + `isOperationalDefault: true`로 표시한다.
모듈 등록 시 이를 검사해, 운영 기본값을 법정 기간처럼 보이게 하면 등록이 거부된다.
